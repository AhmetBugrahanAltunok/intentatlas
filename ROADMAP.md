# Roadmap

## 0.1 — Local intent graph

- [x] Python files, symbols, imports, tests, documents, and Git commits
- [x] Obsidian-compatible project brain
- [x] Local interactive graph viewer
- [x] CLI impact tracing and graph health
- [ ] Public fixtures from real-world repositories

## 0.2 — More languages, richer evidence

- [ ] TypeScript/JavaScript adapter
- [ ] Go and Rust adapters
- [ ] Coverage and test-result evidence import
- [ ] GitHub issue and pull-request linking
- [ ] Stable graph diff format for CI

## 0.3 — Review and change intelligence

- [ ] Pull-request intent completeness check
- [ ] Change-risk explanation with evidence gaps
- [ ] Architecture drift and stale-decision detection
- [ ] Optional local semantic search

## Non-goals

- Uploading private source code to a hosted service by default
- Replacing Git, issue trackers, or Obsidian
- Claiming that generated relationships are verified product requirements
