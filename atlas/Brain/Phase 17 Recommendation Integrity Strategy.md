# Phase 17 Recommendation Integrity Strategy

## Outcome

All supported recommendation surfaces use one confidence and threshold contract, Python src-layout
projects resolve only unique qualified symbols, and a graph test node becomes a runnable candidate
only through bounded eligibility and evidence-strength rules.

## Delivery order

1. **17A - independent reproduction:** freeze the longitudinal baseline, reproduce the Click and
   self-scan observations without changing production, and add red regressions.
2. **17B - confidence integrity:** share the ADR-009 confidence bands and apply the selected
   threshold, counters, omissions, and strategy consistently across ChangeReport and projections.
3. **17C - Python resolution:** recognize bounded Flit, Hatchling, setuptools, and unique
   conventional src layouts, then resolve unique qualified module-symbol chains.
4. **17D - candidate and ranking integrity:** exclude empty markers, preserve the weakest hop, and
   keep bounded co-change below direct structural evidence.
5. **17E - truthful operation and closure:** correct schema documentation, make stale-revision and
   ambiguity wording actionable, record generated-vault governance, and pass every phase gate.
6. **17F - evidence presentation and runnable integrity:** preserve linked primary reasons, expose
   bounded omission totals, distinguish graph artifacts from runnable pytest targets, and explain
   low discovery risk without retuning scores.

## Boundaries

- No project code, build backend, plugin, indexer, compiler, test, hook, or package manager is run.
- Resolver corrections consume only bounded repository metadata and Python ASTs already read by
  the scanner. Non-unique ownership/module/symbol mappings abstain.
- The frozen longitudinal manifest and both partitions remain unchanged. Before/after comparison
  reports effects; it does not relabel cases or claim general accuracy.
- Phase 11C, release, tag, publication, deployment, telemetry, and generated-vault bulk policy
  migration remain outside Phase 17.
